## The one deviation from the decided mechanism

`.mi/docs/memos/distribution.md` decided Option A — git dependency pinned by
commit rev. p0 ran `git init` and added no remote, so this repository has no
fetchable https URL yet, and the proof uses a `file://` URL instead:

```toml
git = "file:///Users/feb/dev/infra/shared"
```

Cargo's git source treats it identically — same fetch, same rev pin, same lock
entry, as the output above shows. **The URL is the half that is provisional;
the `rev =` half is the half being proven, and it does not change.**
`p5-adoption` swaps the `file://` URL for a real remote when this repository
gains one. Nothing else about the mechanism is deferred.
